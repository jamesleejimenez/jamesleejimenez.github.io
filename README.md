# jamesleejimenez.github.io

Source for my portfolio site, live at **https://jamesleejimenez.github.io**

I'm James Lee Jimenez. I evaluate and train large language models at Mercor, and before that I spent five years running the operations side of small businesses. I test AI systems, find where they break, and write down how to fix it.

## What's in here

| File | What it is |
| --- | --- |
| `index.html` | The whole site. Content, styling, and a small script, all in one file. |
| `James-Lee-Jimenez-Resume.pdf` | My resume. |

Nothing to install and nothing to build. GitHub Pages serves `index.html` straight from the `main` branch.

## Changing it

Edit `index.html` and commit. The live site catches up in a minute or two.

All the colours are set once at the top, in the `:root` block. Change `--mark` and the highlight colour updates everywhere it appears. The same set of colours is repeated further down for dark mode.

## Built with

Plain HTML and CSS, with about twenty lines of JavaScript for the theme button and smooth scrolling. Two typefaces from Google Fonts, Bricolage Grotesque for headings and Newsreader for body text. No framework, no build step, no dependencies.
